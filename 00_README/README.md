# SaaS Subscription Analytics — Consulting-Style Capstone

## Scenario
You are the analytics workstream supporting the executive team of **Northstar Cloud**, a synthetic multi-product B2B SaaS company. Leadership wants to improve durable ARR growth, retention, pricing discipline, product adoption, and customer-success productivity.

## Data scale
- Accounts: **8,000**
- Monthly account snapshots: **145,847**
- Invoices: **67,551**
- Support tickets: **36,666**
- NPS surveys: **51,307**
- Analysis window: **Jan 2023 – Sep 2026**

## Tool path
Raw CSV/Excel → PostgreSQL → SQL quality/metric layer → Python EDA & scoring → Power BI → consulting-style executive recommendation.

## Important
This is synthetic training data. The workflow reflects common management-consulting and SaaS analytics practices; it does **not** reproduce proprietary methodology from EY, Bain, McKinsey, or any other firm.
